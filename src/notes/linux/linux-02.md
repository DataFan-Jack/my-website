## 1. Linux 安装方式概述

Linux 系统安装主要有三种方式：物理机安装、虚拟机安装、云服务器。三者各有适用场景，初学阶段推荐虚拟机。

:::diagram
install-methods
:::

### 1.1 物理机安装

直接把 Linux 安装到电脑硬盘，这台电脑只运行 Linux。优点是性能最高、环境完整；缺点是切换系统麻烦、学习成本高。适合企业服务器、专用 Linux 电脑。

### 1.2 虚拟机安装（学习推荐）

在 Windows 中用 VMware 模拟一台虚拟电脑，再在虚拟电脑里安装 Linux。不影响 Windows、可以创建多个 Linux 环境、随时快照恢复，非常适合学习和开发。本知识库的后续操作都基于虚拟机环境。

### 1.3 云服务器

购买阿里云、腾讯云、AWS 等云厂商直接提供的 Linux 服务器，通过互联网远程使用。免安装、可随时访问，适合网站部署、后端服务、生产环境。

## 2. Linux 发行版选择

Linux 不是单一系统，而是一系列发行版。选择发行版时主要看稳定性和适用场景：

| 发行版 | 特点 | 适合 |
| --- | --- | --- |
| Ubuntu | 简单易用、软件丰富、社区大 | 学习、开发、云服务器 |
| CentOS | 稳定，曾大量用于企业服务器；现已停止维护，可用 Rocky Linux / AlmaLinux 替代 | 企业服务器（历史选择） |
| Debian | 稳定、安全，Ubuntu 基于 Debian 开发 | 服务器 |
| Rocky Linux | CentOS 的社区替代品，兼容性高 | 企业 |
| RHEL | 红帽商业服务器系统，技术支持完善 | 大型企业 |

## 5. 虚拟机硬件配置推荐

创建虚拟机时按用途分配硬件。学习 Linux 和大数据环境（Hadoop、Spark、Kafka）的推荐配置不同：

| 资源 | 学习最低 | 学习推荐 | 大数据环境 |
| --- | --- | --- | --- |
| CPU | 2 核 | 4 核 | 4 核 |
| 内存 | 2GB | 4-8GB | 8GB 以上 |
| 硬盘 | 20GB | 40GB+ | 50GB 以上 |
| 网络 | NAT | NAT | NAT / 桥接 |

如果后续要学习 Hadoop、Spark、Kafka，建议直接按大数据环境配置，避免后期扩容。

## 6. Linux 网络模式

VMware 提供三种网络模式：NAT、桥接、仅主机。区别在于虚拟机访问外网的能力，以及能否被外部访问：

:::diagram
net-modes
:::

### 6.1 NAT 模式

虚拟机共享主机网络上网，配置最简单，学习环境首选；外部访问虚拟机需要额外配置。

### 6.2 桥接模式

虚拟机拥有独立 IP，像真实服务器一样接入局域网，适合需要被外部直接访问的场景；缺点是网络环境变化时容易断网。

### 6.3 仅主机模式

只能与主机及虚拟机之间通信，不能访问互联网，适合内部测试环境。

| 模式 | 互联网 | 外部访问 | 用途 |
| --- | --- | --- | --- |
| NAT | ✓ | 较复杂 | 学习 |
| 桥接 | ✓ | ✓ | 服务器 |
| 仅主机 | ✗ | — | 内部测试 |

## 8. Linux 系统初始化

用几条命令快速确认系统状态：

```bash
cat /etc/os-release
uname -a
lscpu
free -h
df -h
```

- **cat /etc/os-release**：查看 Linux 发行版版本
- **uname -a**：查看内核版本与系统架构
- **lscpu**：查看 CPU 信息
- **free -h**：查看内存使用情况
- **df -h**：查看磁盘空间

## 9. Linux 更新系统

Ubuntu 使用 apt 包管理工具更新：

```bash
sudo apt update
sudo apt upgrade
```

**sudo apt update** 更新软件列表，**sudo apt upgrade** 升级已安装软件。首次使用时先执行这两条命令，保证系统处于最新状态。

## 10. SSH 远程连接

SSH（Secure Shell）是一种远程登录协议，作用是不用打开 Linux 图形界面，直接在 Windows 终端登录 Linux 服务器。结构为：电脑上的 SSH 客户端 → Linux 服务器上的 SSH 服务。常用工具：Xshell、MobaXterm、Windows Terminal。

先确认 SSH 服务状态并启动：

```bash
systemctl status ssh
sudo systemctl start ssh
sudo systemctl enable ssh
```

连接步骤：

1. 确认虚拟机 SSH 服务已启动（systemctl status ssh）
2. 查看虚拟机 IP 地址（hostname -I 或 ip addr）
3. 在 Windows 终端执行 ssh 用户名@IP 地址
4. 输入密码完成登录

## 11. 快照管理

虚拟机快照相当于游戏存档：系统安装完成后保存一个快照，之后配置出错、软件装坏，都可以一键恢复到快照状态。流程如下：

1. 安装好干净的 Linux 系统
2. 创建快照（存档）
3. 安装软件、做配置
4. 出现问题
5. 恢复快照，回到干净状态

建议在**系统刚装完**和**每完成一个重要配置**后各打一次快照。

## 12. 常见问题

| 问题 | 解答 |
| --- | --- |
| 学习 Linux 为什么推荐虚拟机？ | 不影响 Windows、可创建多个环境、支持快照恢复，出错成本低。 |
| CentOS 停止维护了还能用吗？ | 已停止维护，生产环境建议改用 Rocky Linux 或 AlmaLinux；学习阶段用 Ubuntu 即可。 |
| NAT 和桥接怎么选？ | 只在自己电脑上学习用 NAT；需要像独立服务器一样被外部访问时用桥接。 |
| SSH 连不上常见原因？ | SSH 服务未启动、IP 地址填错、防火墙拦截，按这三项依次排查。 |
| 快照什么时候打？ | 系统刚装完、每个重要配置完成后各打一次，出问题随时回退。 |
