# mycoden.cn

#### Description
「码上启程」个人学习网站源码。
基于 Vue 3 + Vite 开发，采用黑金主题风格，涵盖首页、学习中心、教程、项目实战、编程导航、人生指南、关于我七大板块。
内置文章阅读、标签分类、搜索、收藏与 GitHub OAuth 登录等功能，并适配 PC 与移动端。项目持续更新，作为个人技术成长与知识沉淀的展示。
