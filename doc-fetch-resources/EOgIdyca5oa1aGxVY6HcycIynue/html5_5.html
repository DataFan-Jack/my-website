VMware 网络模式对比按“是否上外网、能否被外部访问”选择
NAT 模式学习推荐
Linux 虚拟机→VMware 虚拟网络→Windows 主机→互联网
虚拟机共享主机网络上网，配置最简单，适合学习环境。
互联网：✓ 可上网
外部访问：较复杂，需配置端口转发
桥接模式
路由器 / 交换机
├─Windows 主机├─Linux 虚拟机
虚拟机在局域网中拥有独立 IP，像一台真实服务器。
互联网：✓ 可上网
外部访问：可直接访问；网络环境变化容易断
仅主机模式
Linux 虚拟机↔VMware 虚拟网络↔Windows 主机
只能与主机和虚拟机之间通信，不能访问互联网。
互联网：✗ 不可上网
用途：内部测试、隔离环境
