三种 Linux 安装方式按学习阶段选择，初学推荐虚拟机
物理机安装
直接把 Linux 装进电脑硬盘，独占整台机器运行。
优点：性能最高、环境完整
缺点：切换系统麻烦、学习成本高
适合：企业服务器、专用 Linux 电脑
虚拟机安装学习推荐
在 Windows 中用 VMware 模拟一台虚拟电脑，再在虚拟电脑里装 Linux。
优点：不影响 Windows、可建多个环境、支持快照恢复
缺点：性能略低于物理机
适合：学习与开发（本知识库采用此方式）
云服务器
购买阿里云、腾讯云、AWS 等云厂商直接提供的 Linux 服务器。
优点：免安装、随时访问、生产级环境
缺点：按量付费
适合：网站部署、后端服务、生产环境
